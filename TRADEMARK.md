# Trademark and branding policy

The source code in this repository is free software (see [LICENSE](LICENSE)). This policy
covers what the code license does **not** grant: the project's identity.

This repository builds **Shoutkit for Windows**, part of the same Shoutkit product as the
[iOS](https://github.com/cascadiacollections/shoutkit) and
[Android](https://github.com/cascadiacollections/shoutkit-android) apps. The repository and
project name `smodr` is a historical host name only; it is not the product name, and the
separate Smodr Android podcast app has its own policy.

- The name **"Shoutkit"** as the name of an app or distributed product
- The Shoutkit app icon, tile and splash artwork (`smodr/Assets/`), store listing graphics,

- The package identity in `smodr/Package.appxmanifest` on any app store

These remain the property of Kevin T. Coughlin and may not be used to name, brand, or market a
fork or derived product without written permission.

## What you can do freely

- Fork, modify, build, and redistribute the code under its license —
  **under a different app name, icon, and package identity**
- Build and install the app from source for yourself, unchanged, including its name and icon
- Use the name "Shoutkit" nominatively: to refer to this project in articles, reviews,
  compatibility notes ("based on Shoutkit"), and attribution

## Why

This is the standard FOSS arrangement (used by Firefox, VLC, and many others): the code is free,
the identity is not. It protects users from confusing or misleading clones — including
repackaged copies on app stores — without restricting any freedom the license grants.
