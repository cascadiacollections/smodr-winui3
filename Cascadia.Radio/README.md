# Cascadia.Radio (pre-release source)
MIT, .NET 10, no WinUI or Windows SDK dependency. Namespaces remain smodr.Models and smodr.Services during this compatibility-first extraction; these are not yet a frozen public API.
Supply storage paths, HTTP clients, privacy policy and lifecycle management from your host. Diagnostics are silent until explicitly configured by the host. Optional persistence/catalog services still use reflection-based JSON and are not advertised as trim/AOT safe.
No package has been published. See ../RADIO_SDK.md in the source repository for boundaries and migration notes.
